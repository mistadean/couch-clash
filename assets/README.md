# Character art

The Couch Clash crew (generated with ChatGPT, cropped to transparent 440×440 WebP):

- `critter-0.webp` Rumble (red): robot rhino-beetle brawler
- `critter-1.webp` Nova (blue): lanky alien space pilot
- `critter-2.webp` Zip (yellow): tiny jetpack space monkey
- `critter-3.webp` Glorp (green): one-eyed swamp alien

To swap a character, replace its file (square, transparent, feet at the bottom). If a file is missing,
the game falls back to the built-in drawn critter.
