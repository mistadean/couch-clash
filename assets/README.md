# Custom character art (optional)

Drop four square, transparent PNGs here to replace the drawn critters:

- `critter-0.png` red (horns)
- `critter-1.png` blue (antenna)
- `critter-2.png` yellow (ears)
- `critter-3.png` green (sprout)

About 512×512, character facing the viewer, centred, with some empty space around it.
If a file is missing, the game falls back to the built-in drawn critter.
