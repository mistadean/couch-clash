# Couch Clash

Free arcade party games for 2–4 players. The TV (or laptop) is the console, phones are the controllers.

**Play:** https://mistadean.github.io/couch-clash/

1. Open the link on the TV or laptop. It opens the host screen automatically (add `?menu` to see the menu).
2. Everyone scans the QR code (or opens the link and taps **Join**) and enters the room code.
3. The leader taps **Start**. Bots fill empty seats.

Games: Goal Guard, Ice Sumo, Tile Takeover. Keyboard players: WASD + Space, Arrows + Enter.

Connections use PeerJS (WebRTC); game data goes straight between devices.
